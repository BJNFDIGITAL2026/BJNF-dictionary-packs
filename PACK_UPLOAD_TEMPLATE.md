# Language Pack Upload Checklist

- [ ] Language name and BCP-47 language code recorded
- [ ] Upstream project and exact source version recorded
- [ ] Source URL recorded
- [ ] License verified for the actual data files
- [ ] Commercial use and redistribution permissions checked
- [ ] Attribution and NOTICE requirements included
- [ ] Modifications documented
- [ ] Pack filename and version assigned
- [ ] File size recorded
- [ ] SHA-256 checksum generated and verified
- [ ] Android compatibility tested
- [ ] iOS compatibility tested (where applicable)
- [ ] Telugu transliteration/suggestion tests passed (where applicable)
- [ ] Manifest updated only after all checks pass
