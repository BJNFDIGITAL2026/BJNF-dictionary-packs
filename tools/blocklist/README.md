# Offensive-word blocklists

Words listed here are removed from the published packs so the keyboard never suggests them.
Users can still type anything; the words are only kept out of suggestions.

Format: one entry per line. `word` removes that exact word; `word*` removes every word that starts with it.
Use `*` only for roots that cannot start a normal word. `#` starts a comment.

These starter lists are short on purpose. A native-speaker reviewer should add entries found in `review/<code>/`.
